# 更新日志红点提醒 — 简版需求

管理端提供更新日志配置与发布能力，不强制绑定前端版本号。运营在管理端填写发布日期、多语言标题和内容摘要后点击发布，系统生成新的 `changelogId`；中文与英文为必填语言，其他语言（繁中、日韩、德法西俄等）可按需添加；内容摘要支持换行分条展示，不允许出现空行。

用户端页面加载时请求最新 `changelogId`，并与浏览器本地 `localStorage.df_changelog_seen_id` 对比；如果两者不同，则更新日志入口展示红点。该逻辑不区分登录态，管理端每次发布新的 `changelogId` 后，所有用户下次刷新页面都会重新判断红点状态。

用户点击一次更新日志红点/入口后，前端将当前 `changelogId` 写入 `localStorage.df_changelog_seen_id` 并隐藏红点；只要浏览器缓存未失效，后续访问不再显示红点。若用户清缓存、换浏览器/设备，或管理端再次发布新的 `changelogId`，红点会重新出现。
