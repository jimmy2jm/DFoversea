# DF 海外工具站 数据结论（09-04 ~ 10-09）

> 数据来源：每日流量趋势报表、各个事件上报明细；埋点口径见在线表「DF工具箱dftools」。
> 口径说明：PV/UV 为首页曝光事件（hq_home_page）；留存分母为当日全部 UV（新老混合，非纯新用户留存）。

## 一句话结论

**流量由 09-04 拍脸推广带起，随后回落到日均约 2.2~2.5 万 UV 的稳态，仍在缓降；拍脸结束后留存明显变好，各功能人均触达率持续上升，说明留下的是真实使用工具的用户；分享类功能基本没有转化。爆破为新模式，数据待补。**

## 背景事件

| 时间 | 事件 | 对数据的影响 |
|---|---|---|
| 09-04 | 端内拍脸推广 | 单日 19.5 万 UV（5 周内峰值），3 天累计 34.4 万，占 36 天总 UV 的 26% |
| 09-27 前后 | 周年庆（无额外资源位） | 09-25~27 日均 2.9 万，比前后工作日高约 25%，扣除周末效应约 +10%，仅随游戏日活轻微增长 |
| 10-01~10-07 | 国庆假期 | 10-03/04 为 2.6~2.7 万，与普通周末持平，无明显假期效应 |

## 1. 流量：拍脸脉冲 → 缓降稳态

- 09-04 峰值 19.5 万 → 09-09 降到 4.3 万 → 09-15 起降到 3 万以内。
- 稳态周均 UV：**29.1k → 25.4k → 24.5k → 22.2k**（09-14 起每周），降速在放缓，周末比工作日高约 9%。
- 近 3 天 20.5k → 24.7k，小幅回升。
- 人均 PV 从 1.42（09-04）升到 1.61（10-09），用户页面浏览深度在增加。

## 2. 留存：拍脸期低，之后明显改善

| 阶段 | D1 | D7 |
|---|---|---|
| 拍脸期 09-05~09-18 | 15.2% | 6.5% |
| 稳态 09-19 之后 | **18.0%** | **8.3%** |

- 首日（09-04）用户 D1 11.4%、D7 3.4%，推广带来的用户意向偏弱。
- D14 约 5~6%；D30 仅 09-04~09-09 这批有数（1.8%~2.8%，含拍脸用户），稳态用户的 D30 还需再等一周。

## 3. 功能触达（近 7 天日均 UV 占首页 UV）

| 功能 | 触达 | 趋势（09-14 起首周 → 最近一周） |
|---|---|---|
| 资产周历入口 | 20.9% | 16.7% → 20.8% ↑ |
| 更新日志入口 | 19.8% | 持平后上升 |
| 我的数据 | 22.8%（其中约 30% 会点战绩详情） | 19.0% → 22.9% ↑ |
| 收集册入口 | 15.6% | 10.7% → 15.6% ↑（点卡牌详情 6.7%，生成海报 2.6%） |
| 大红展馆 / 制造 | 曝光 42.5% / 36.9% | 均上升后走平 |
| 改枪 | 复制改枪码 4.8%，点详情 5.1% | 小幅上升后走平 |
| Wiki（09-28 起） | 5.8% | 上线即稳定 |
| 登录入口 | 9.3% | 6.4% → 9.3% ↑ |
| 日报分享 | 点按钮 0.85%，实际分享约 0.18% | 几乎无转化 |
| 分享回流（二维码） | 日均约 11 UV | 近乎为零 |

- 稳态用户的功能使用率几乎全线上升，是"留下的用户更精准"的表现，不是产品触达能力变强。
- 日报/海报分享基本没人用，可不作为后续重点。

## 5. 数据可信度提示（影响结论的几项）

- `hq_share_card_box_entry` 在 09-19 从约 1.2 万 UV 骤降到几十，口径可能有变，不建议用来衡量分享裂变。
- `hq_click_red_poster_share_channel` 日均仅约 2 次，疑似未正确上报。
- `hq_page_leave` 只覆盖约 69% 的首页 UV，停留时长偏向多页用户。
- 当前数据没有端、语言、新老用户、参数维度的拆分，以上均为整体口径。
