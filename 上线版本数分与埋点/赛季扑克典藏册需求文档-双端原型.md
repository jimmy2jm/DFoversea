# 赛季扑克典藏册 — 需求文档（双端原型）

> **产品名称**：Delta Force 海外版工具站  
> **版本**：原型 V1  
> **适用端**：Desktop (PC Web) + Mobile (H5)  
> **文档性质**：纯原型交互需求，不含后端接口、数据结构与多语言

---

## 一、功能说明

在「大红展馆」模块中新增「赛季扑克牌收藏册」入口，点击后打开收藏册，展示本赛季全部 55 张卡牌的收集状态，支持按拥有状态、花色分类筛选，并支持查看单张卡牌详情与生成分享海报。

- 全部卡牌（含未拥有）均需完整展示，未拥有卡牌以锁定态呈现。
- 每张卡牌标注品阶，品阶与颜色一一对应。
- 收藏进度与单张已拥有卡牌均支持生成分享海报。

---

## 二、入口位置

### 2.1 Desktop 端

入口位于首页「大红展馆」模块内部，标题栏之后、原统计区域之前。

- 点击入口或「查看收藏册」均打开收藏册弹窗。
- 不新增独立页面，不影响原有大红物品、出红记录、生成海报功能。

### 2.2 Mobile 端

入口位于「我的」页面 →「大红藏馆」内容 Tab 区域下方、原有「生成海报」按钮上方。

- 仅切换到「大红藏馆」Tab 时显示。
- 点击后打开全屏收藏册子页面（非底部导航新增 Tab）。
- 子页面宽度固定为移动端视口宽度，不出现横版布局。

---

## 三、卡牌品阶

每张卡牌固定一个品阶，品阶与颜色映射如下：

| 品阶 | 颜色 |
|------|------|
| 1 | 白 |
| 2 | 绿 |
| 3 | 蓝 |
| 4 | 紫 |
| 5 | 金 |
| 6 | 红 |

品阶以数字 icon 呈现，背景色与品阶颜色一致。已拥有与未拥有卡牌均展示品阶 icon。

---

## 四、卡牌结构

共 55 张，固定分组：

| 分组 | 数量 |
|------|------|
| 牌盒 | 1 |
| 大小王 | 2 |
| 黑桃 | 13 |
| 红桃 | 13 |
| 梅花 | 13 |
| 方块 | 13 |

每张卡牌包含以下属性（以 `data-*` 存储，不建独立数据文件）：

- 卡牌名称
- 编号
- 花色分组
- 品阶
- 牌色（品阶对应的颜色名）
- 拥有状态（owned / locked）
- 拥有数量

---

## 五、收藏册页面

### 5.1 顶部进度区

展示：

- 当前进度：`13/55`
- 统计：已拥有、未拥有、集齐花色
- 进度条
- 生成分享海报入口

### 5.2 状态筛选 Tab

提供三个筛选：

| 筛选 | 行为 |
|------|------|
| 全部 | 显示所有卡牌 |
| 已拥有 | 仅显示已解锁卡牌 |
| 未拥有 | 仅显示锁定卡牌 |

筛选为真实的内容显示/隐藏，不是仅切换样式。筛选后保留分组标题与分组计数。

### 5.3 分类筛选 Tab

按花色分组筛选：

- 全部
- 牌盒
- 大小王
- 黑桃
- 红桃
- 梅花
- 方块

每个分类 Tab 标注当前拥有数 / 总数。分类与状态筛选可叠加生效。

### 5.4 卡牌展示区

**Desktop 端**：

- 分组网格布局，每行多张卡牌。
- 卡牌固定尺寸，不随数量变化。
- 弹窗固定高度，内容超出时内部滚动。

**Mobile 端**：

- 单列分组，组内横向滚动。
- 卡牌固定尺寸。
- 页面纵向滚动。

### 5.5 尺寸约束

- 收藏册容器、卡牌网格、卡牌本身均固定尺寸。
- 筛选导致卡牌数量变化时，容器尺寸不随之伸缩。
- 未拥有卡牌与已拥有卡牌占位比例一致。

---

## 六、卡牌详情

点击任意卡牌（已拥有或未拥有）打开详情弹窗。

### 6.1 已拥有卡牌

展示：

- 卡牌名称
- 卡牌大图 / 符号
- 编号
- 解锁状态：已拥有
- 牌色
- 品阶 icon
- 拥有数量
- 生成这张卡的海报入口

### 6.2 未拥有卡牌

展示：

- 卡牌名称
- 卡牌编号
- 解锁状态：尚未解锁
- 牌色
- 品阶 icon
- 拥有数量：0

未拥有卡牌详情**不展示**完整卡面信息，不提供海报入口。

---

## 七、分享海报

### 7.1 收藏进度海报

从收藏册顶部「生成分享海报」入口触发。

**尺寸与方向**：

- 横版 16:9（1200 × 675）
- 适配社媒平台分享预览（Discord、X、Facebook）

**海报内容**：

- 站点标识 + 赛季扑克牌收藏册标题
- 总进度：`13/55` + 进度条
- 核心统计：已拥有、未拥有、集齐花色、拥有总数量
- 分类收集明细：每个花色的独立进度（已拥有/总数 + 进度条）
- 已拥有卡牌缩略明细：展示所有已拥有卡牌的花色、编号、品阶、数量
- 最近解锁卡牌
- 工具站域名：`playdeltaforce.com/events/hq/`
- 二维码视觉区

**交互**：

- 打开海报预览弹窗，弹窗本身保持当前端宽度，不撑成横版页面。
- 提供关闭、保存海报操作。
- 海报内容从当前收藏册静态卡牌读取，不引入独立数据源。

### 7.2 单张卡牌海报

从已拥有卡牌详情弹窗「生成这张卡的海报」入口触发。

**海报内容**：

- 卡牌名称
- 卡牌符号
- 品阶颜色
- 拥有状态
- 拥有数量
- 工具站域名
- 二维码视觉区

未拥有卡牌不提供此入口。

---

## 八、视觉规范

- 直角，不使用圆角卡片。
- Desktop 强调色 `#24f4b2`，Mobile 强调色 `#00d4aa`。
- 卡牌区使用深色 + 红黑金视觉，外围 UI 与工具站深青绿体系一致。
- 已拥有卡牌显示完整卡面；未拥有卡牌灰度 + 低透明度 + 锁标识。
- 关键数字使用 Orbitron 字体。
- 不使用翻转、弹跳、大范围缩放动画，仅保留边框高亮与透明度过渡。

---

## 九、不做的事项

本期明确不做：

- 后端接口与数据结构
- 真实赛季切换
- 账号同步
- 卡牌获取记录与时间线
- 多语言翻译
- 独立 `collection.html` 页面
- 底部导航新增 Tab
- 复杂翻牌 / 3D 动画
