# 爆破背包流派管理 — 需求文档

> 模块入口：CMS → 改枪码推荐 → 爆破模式（与「烽火配置」「全面战场配置」并列）
> 版本：v1.0 · 2026-08-27

---

## 1. 背景与范围

- 运营在管理端配置并发布爆破模式「背包流派」：1 套背包 = 16 把枪的固定出装配置 + 1 个背包码，供前台（桌面 / 移动）展示与复制。
- 管理粒度仅为背包流派；**不建设单枪方案库**，枪械配置只存在于所属背包的 16 个槽位中。
- 前台统计（复制 / 点赞）以背包流派为主体。

## 2. 流派列表

**筛选条件（支持回车查询与一键重置）**

| 条件 | 匹配方式 |
|---|---|
| 流派名称 | 模糊 |
| 流派 ID | 精确 |
| 作者 | 模糊 |
| 包含枪械 | 在 16 个枪位名称中模糊匹配 |
| 渠道 | 精确（LI / GA） |

**列表字段**

| 字段 | 说明 |
|---|---|
| 流派 ID | 唯一标识，如 BP-000128 |
| 流派名称 | 中文名称 |
| 渠道 | LI（Level Infinite）/ GA（Garena） |
| 流派码 | 运营手动配置的背包码；未填显示 — |
| 作者信息 | 昵称 + 平台 |
| 优先级 | 范围 1-9999，数值越大 C 端展示越靠前 |
| 最后编辑 | 最近编辑人 |
| 发布状态 | 草稿 / 已发布 / 已下线 |
| 更新时间 | 最近一次保存时间 |
| 操作 | 编辑、删除（删除需二次确认，不可恢复） |

点击行或流派名称可进入流派详情。

## 3. 流派详情

- 头部信息：名称、作者、介绍、16 枪完整度、积分区间、标签。
- 枪械预览：按 手枪 / 标准 / 精锐 / 特种 四级分组展示，点击枪卡可直达对应槽位的编辑弹窗（标配除外）。
- 侧栏信息：背包 ID、流派码（可复制）、版本、状态、前台复制 / 点赞数据、最近编辑。

## 4. 新建 / 编辑流派

### 4.1 基础信息

| 字段 | 必填 | 说明 |
|---|---|---|
| 名称（中文） | 是 | 最多 50 字，带字数统计 |
| 名称（英语） | 是 | 最多 50 字，带字数统计 |
| 名称多语言 | 已添加必填 | 可选添加 13 种语言（德/法/俄/日/韩/繁中/西/葡/土/阿/越/泰/印尼） |
| 背包码 | 是 | 运营手动配置，发布后前台复制即得此码 |
| 关联作者 | 是 | 从作者库选择，仅引用、不在此修改作者资料 |
| 介绍（中文） | 否 | 一句话介绍 |
| 介绍多语言 | 否 | 可选添加 14 种语言（含英语），建议填写 |
| 流派标签 | 否 | 运营自定义标签 |

### 4.2 16 把枪配置

- 固定结构：手枪 / 标准 / 精锐 / 特种 × 各 4 把，恒为 16 把、无空位。
- 手枪第 1 槽固定为 G17-标配：无改枪码、不可编辑。
- 单枪字段：名称（中文）*、名称（英语）*、积分价格*（100-10000）、名称多语言（非必填）、改枪码*、描述（可选）。

### 4.3 改枪码配置

- 选择渠道（LI / GA）后粘贴游戏内导出的改枪码，点击「查询」自动解析。
- 解析结果展示：枪械信息（名称、类型、ID）+ 配件明细列表（配件名、部位 · 分类、数量、配件 ID）。
- 解析成功后自动回填枪械中英文名称，可手动微调。
- 渠道或码变更后需重新查询，否则不可保存。

## 5. 发布与状态

- 状态流转：草稿 → 已发布 → 已下线，已下线可重新发布。
- 不做发布前校验清单；点击「直接发布」时仅检查必填项是否填写（中英文名、背包码、作者、已添加的多语言项、16 枪位及改枪码完整），有缺失则以提示一次性列出。
- 已发布背包的后续修改通过创建新草稿版本完成，支持查看版本间差异。
- 背包码为手动配置，发布即时生效。

## 6. 其他

- **前台预览**：发布前可预览桌面端 / 移动端展示效果；预览中的复制按钮不写入真实统计。
- **新建流派**：生成空白草稿，默认渠道 LI、优先级 1。
- **作者库 / 标签库**：复用现有模块，本期不在本页范围内。
