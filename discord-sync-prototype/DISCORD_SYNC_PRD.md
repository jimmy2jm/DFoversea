# 改枪方案 Discord Bot 同步 — 需求说明

## 背景

当前改枪方案在管理端配置完成后，运营需手动搬运到 Discord 频道发布，流程繁琐且不可追溯。本次新增一套 Discord Bot 同步管理后台，运营可以手动选择方案、配置发布频道，由 Bot 拉取任务后在 Discord 上逐条发送。

## 核心流程

```
方案管理页（线上已有）
  → 点击「Discord 同步管理」进入同步页
    → 在「烽火方案」「战场方案」Tab 中勾选待发布方案
      → 点击「发布到 Discord」
        → 弹出确认窗口：
            · 顶部选择目标频道（Global / Japan，支持多选）
            · 若勾选 Japan → 检查日语多语言配置 → 缺失时阻止发布，引导仅发布 Global
            · 若包含已发布方案 → 显示重复发布提醒
            · 按频道分组预览每条消息
          → 确认发布 → Bot 执行发送
```

## 页面说明

### 同步管理页

| 区域 | 说明 |
|------|------|
| Tab 栏 | 烽火方案 / 战场方案 / 发帖历史，按模式区分。发帖历史不含勾选和发布功能 |
| 筛选区 | 名称、方案ID 两个输入框（烽火/战场 Tab 共用，发帖历史隐藏），支持筛选和重置 |
| 方案列表 | 表格展示方案，列：复选框、方案ID、预览图、方案名称、关联枪械、改枪码、价格、标签、作者、最后编辑人、更新时间 |
| 底部按钮 | 「发布到 Discord」，未选方案时禁用 |

### 方案选择逻辑

- 未发布的方案自动勾选，已发布的方案取消勾选但不禁用（运营可手动勾选再次发布）
- 支持「全选」「一键选择未发布」
- 已同步方案行透明度降低，视觉区隔

### 确认发布弹窗

弹窗从上到下依次为：
- **频道选择区**：标签形式（Global / Japan），多选，默认全选
- **日语缺失提醒**：若勾选了 Japan，自动检查选中方案的日语多语言配置状态；缺失的方案列表以黄色警告展示，底部按钮变为「仅发布到 Global」和「取消」，不允许发布到 Japan
- **重复发布提醒**：若选中已发布过的方案，显示黄色警示
- **消息总数** + 频道标签
- **预览卡片（可滚动）**：按频道分组，每组逐条展示方案标题 + 改枪码 + 价格 + 标签 + 预览图

每个方案 × 每个频道 = 一条独立 Discord 消息。

## 发帖历史

以表格形式展示所有同步任务记录。

| 列 | 说明 |
|----|------|
| 任务ID | 唯一标识 |
| 频道 | Global / Japan |
| 方案 | 武器名 · 方案名 |
| 方案ID | 原始方案ID |
| 发送时间 | 任务执行时间 |
| Discord 消息链接 | 可跳转到对应消息 |
| 👍 点赞 | Discord 帖子反应数 |
| 💬 评论 | Discord 帖子回复数 |
| 状态 | 已完成 / 执行中 / 待执行 |
| 操作 | 删除 — 同时从本地记录和 Discord 中移除对应消息 |

## 不做的事情

- ❌ 方案新增/修改时自动同步到 Discord
- ❌ 多个方案合并为一条 Discord 消息
- ❌ 已发送消息的内容编辑（可通过删除后重新同步覆盖）
- ❌ 同步页内编辑方案字段（方案编辑仍在方案管理页完成）

## 后续可扩展

- 定时发送策略（如每周一自动拉取未同步方案）
- 不同频道使用不同消息模板
- 同步结果回传到方案表展示最近同步时间
- 筛选区增加更多维度（标签、作者等）
