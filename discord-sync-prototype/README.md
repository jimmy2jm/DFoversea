# 改枪方案 Discord Bot 同步 — 需求说明

## 背景

改枪方案当前在管理端配置完成后，需要运营手动搬运到 Discord 频道发布，流程繁琐。本次新增一套 Discord Bot 同步管理后台，运营可以手动选择方案、配置发布频道和时间，由 Bot 拉取任务后逐条发送。

## 核心原则

- **不做自动同步**：管理端新增方案后不自动推送到 Discord。
- **每条方案独立发送**：每个改枪码单独作为一条 Discord embed 消息发布到频道。
- **手动选择 + 自动提示**：管理端卡片列表中自动勾选所有未发布方案，运营可自行调整。
- **支持立即/定时发布**：可即时推送或指定未来时间，Bot 到时间后拉取任务逐个发送。
- **可查看发帖历史**：页面内展示所有历史同步任务的状态（待执行 / 执行中 / 已完成）。

## 管理端交互

### 列表页（index.html）

- 展示所有改枪方案及 Discord 同步状态（已同步/未同步）
- 点击「Discord 同步管理」进入同步管理页

### 同步管理页（sync-manager.html）

该页面是一个完整的 Bot 发帖管理后台，分为四个区域：

| 区域 | 内容 |
|------|------|
| **同步配置** | 选择目标 Discord 频道（下拉）、选择发送时间（立即/定时） |
| **待发布方案** | 卡片式列表，**自动勾选所有未同步方案**；支持全选/一键选择未发布 |
| **消息预览** | 每个被选中的方案生成一条独立的 Discord embed 预览，实时渲染效果 |
| **发帖历史** | 表格展示所有历史同步任务：任务ID、频道、方案数、发送时间、状态 |

### 提交逻辑

- 点击「发布到 Discord」后，为每一条选中方案创建独立的同步任务
- Bot 从 `GET /api/sync-tasks/pending` 拉取待执行任务
- Bot 逐条调用 Discord API 发送 embed 消息
- Bot 执行完成后通过 `PATCH /api/sync-tasks/:id` 更新状态

## 不做的事情

- ❌ 新增方案自动触发同步
- ❌ 多个方案合为一条消息
- ❌ Bot 直接操作管理端数据库
- ❌ 已发送消息的在线编辑/删除

## 后续可扩展

- 同步记录页面：查看每条方案的历史发帖详情与 Discord 消息链接
- 定时策略：支持每日/每周定时自动拉取未同步方案
- 多频道模板：不同频道使用不同消息样式
