1Phase 1 — 埋点上报（数据采集层）

1.1 当前埋点覆盖评估

⚠ 已有埋点的问题

现有 25 个事件以曝光(vshow) + 点击(click)为主，能回答"用户做了什么"，但无法回答：

  • ❌ 停留多久 — 没有页面停留时长 / 会话时长相关事件
  • ❌ 浏览到哪里 — 没有滚动深度上报
  • ❌ 为什么离开 — 没有页面离开/关闭事件
  • ❌ 配装模块操作 — 没有选择武器、查看方案、复制配装码的事件
  • ❌ 跳蚤市场/合成台操作 — 相关页面无任何交互埋点

1.2 建议补充的埋点（按优先级）

优先级事件名（建议）类型参数解决的分析问题

1.3 上报时机规范

事件类别触发时机注意事项
页面曝光 (vshow)DOM loaded + 首屏渲染完成同一页面同一会话仅上报一次
区域曝光 (vshow)IntersectionObserver 进入可视区 50%+每个元素每次会话仅触发一次
点击事件 (click)用户主动点击/触摸每次点击都上报，不去重
停留时长visibilitychange=hidden 或 beforeunload计算从 page_show 到当前的差值
滚动深度滚动停止 + 达到阈值（25/50/75/100%）每个阈值仅触发一次
会话开始/结束首次事件触发/30min无操作或页面关闭会话超时阈值 30 分钟

2.2 用户访问足迹还原

方法：基于事件序列构建用户 Session Path

按 open_id + 会话窗口(30min)，将事件按时间排序，形成用户路径：

路径类型典型序列占比（预估）诊断意义
单页跳出hq_home_page → (离开)~30-40%首页未产生足够吸引力
浏览型home → my_data → (离开)~25%查看数据后未找到下一步价值
功能使用型home → gun_builds → 选枪 → 复制~15%核心价值路径，需提升此类占比
深度探索型home → my_data → 模式切换 → 战绩 → 分享~10%高粘性用户，关注其特征

依赖事件：hq_exp_page(page_id) + hq_page_leave + hq_page_stay_duration 构建完整路径

2.3 流失节点定位

按页面维度：哪些页面流失率最高？

分析维度计算方式预期发现
页面退出率从该页面结束会话的次数 / 该页面 PV定位哪个页面是"终点站"
页面跳出率仅看了该页就离开 / 该页作为着陆页的次数着陆页吸引力问题
停留时长中位数按 page_id 分组的 duration 中位数时长过短=未阅读；过长=找不到目标
滚动深度分布达到 25/50/75/100% 的用户占比内容排布是否合理

按用户维度：什么样的用户更容易流失？

用户分群定义关注指标
游客用户未登录（open_id 为空或匿名）vs 登录用户的 PV、停留时长对比
首次访问当日 session_start.is_new_user=1新用户首屏行为、是否触达核心功能
"无角色"用户触发 hq_exp_login_norole 的用户后续是下载游戏 or 彻底流失？
只看不操作仅有 vshow 无 click 事件页面交互引导是否足够

3Phase 3 — 归因假设 & 产品优化

3.1 基于线上产品的初步假设

根据对线上 PC端（playdeltaforce.com/events/hq/zh-tw/）和移动端的观察：

#假设验证数据优化方向
H1 首页信息密度过高：日报+密码房+展馆一屏堆叠，用户不知道做什么 首页滚动深度（预估多数用户 <50%）
首页停留时长 vs 跳出率关系		 首页增加明确的功能导航卡片，引导至配装/战绩等核心功能
H2 未登录用户无内容可看："我的数据"需登录才有内容，游客直接流失 游客用户的页面路径（是否只停留在首页）
登录弹窗曝光后 dismiss 比例		 提供 Demo 数据/示例战绩，降低登录门槛感知
H3 配装功能入口不明显：核心工具价值（配装码复制）在导航深处 gun_builds 页 PV 占总 PV 的比例
从首页到 gun_builds 的跳转率		 首页增加"热门配装"快捷入口卡片
H4 "无角色"流失严重：未找到角色后，玩家放弃整个工具站 hq_exp_login_norole 后的行为（download / otheraccount / dismiss 占比） 无角色状态下仍展示公共数据（武器meta、市场行情）
H5 移动端功能割裂：底部仅 Daily Data / My Data，缺少配装/市场入口 移动端 PV 集中度（是否 90%+ 在首页）
移动端人均 PV 对比 PC		 移动端底部导航增加"配装"和"市场"Tab
H6 内容更新频率不够：日报内容固定，无回访动力 回访用户的 DAU/WAU 比值
7日留存曲线斜率		 增加每日变化元素（当日 meta 推荐、赛季进度）

4Phase 4 — 效果验证 & 持续迭代

验证节奏

时间点动作关注数据
上线 D+1验证埋点数据质量新事件是否正常上报、参数是否完整

每周周报看板 review异常波动 → 归因 → 新假设 → 新实验

迭代判断标准

  • 正向信号：核心转化率(复制/分享)↑、人均PV↑、D2留存↑ → 继续优化此方向
  • 中性信号：指标未明显变化 → 检查是否曝光量不足、实验周期太短
  • 负向信号：跳出率↑、停留时长↓ → 回滚改动，重新分析
