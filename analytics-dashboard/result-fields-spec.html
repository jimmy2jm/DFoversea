DFoversea 看板 — 结果字段需求清单

说明：以下为看板展示所需的全部预计算结果字段，由后端按日聚合后直接输出给前端展示，无需前端二次计算。
粒度：每行 = 1 天的数据 | 筛选条件：开始日期 ~ 结束日期

表 1: 每日流量汇总

用于：KPI 卡片 + DAU/PV 日趋势折线图

字段名类型口径说明用途
datedate日期X 轴 / 筛选
pvint当日页面浏览总次数KPI + 趋势图
uvint当日去重访客数KPI + 趋势图

表 2: 页面级 PV/UV

用于：页面 PV/UV 双柱状图

字段名类型口径说明用途
datedate日期筛选
page_idstring页面标识：home / my_data / gun_builds / market / craftX 轴分组
page_pvint该页面当日浏览次数蓝色柱
page_uvint该页面当日去重访客数橙色柱

表 3: 登录方式分布

用于：登录方式饼图 (LI / Garena)

字段名类型口径说明用途
datedate日期筛选
login_methodstringlevel_infinite / garena饼图分片
method_uvint选择该方式的去重用户数占比计算
method_pvint选择该方式的总次数备用

表 4: 游戏模式分布

用于：游戏模式饼图 (SOL / MP)

字段名类型口径说明用途
datedate日期筛选
game_modestringsol / mp饼图分片
mode_uvint切换到该模式的去重用户数占比计算
mode_pvint切换到该模式的总次数备用

表 5: 平台分布

用于：平台饼图 (PC / iOS / Android)

字段名类型口径说明用途
datedate日期筛选
client_typestringPC / iOS / Android饼图分片
platform_uvint该平台当日去重用户数占比计算
platform_pvint该平台当日总事件数备用

表 6: 登录漏斗

用于：登录转化漏斗图

字段名类型口径说明用途
datedate日期筛选
login_click_uvint点击登录按钮的去重用户数漏斗第1步
login_modal_uvint登录弹窗曝光的去重用户数漏斗第2步
login_method_uvint选择登录方式的去重用户数漏斗第3步
login_submit_uvint提交登录请求的去重用户数漏斗第4步
login_success_uvint登录成功的去重用户数漏斗第5步

表 7: 日报分享漏斗

用于：分享转化漏斗图

字段名类型口径说明用途
datedate日期筛选
report_exp_uvint日报卡片曝光的去重用户数漏斗第1步
share_btn_uvint点击分享按钮的去重用户数漏斗第2步
poster_exp_uvint海报弹窗打开的去重用户数漏斗第3步
poster_share_uvint完成渠道分享的去重用户数漏斗第4步

表 8: 分享渠道每日明细

用于：分享渠道堆叠柱状图（X 轴=日期，按渠道堆叠）

字段名类型口径说明用途
datedate日期X 轴
share_channelstringsave_image / x / discord / facebook / reddit堆叠颜色分组
channel_pvint该渠道当日分享次数柱高
channel_uvint该渠道当日去重用户数备用

表 9: 事件明细表

用于：事件明细数据表（表头：日期 / 事件名 / PV / UV）

字段名类型口径说明用途
datedate日期表格列
event_namestring事件名称（如 hq_exp_page、hq_click_login_entry 等）表格列
event_pvint该事件当日总触发次数表格列
event_uvint该事件当日触发的去重用户数表格列
