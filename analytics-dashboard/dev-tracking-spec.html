1.1 所有事件的通用参数（每次上报必带）

参数名类型说明取值示例

1.2 事件类型

子事件名称含义触发场景
cm_vshow曝光页面/区域进入可视区时上报
cm_click点击用户主动交互时上报

1.3 上报时机规则

场景触发时机去重规则
页面级曝光页面 DOM 加载完成后同一页面同一会话仅上报 1 次
区域级曝光IntersectionObserver 检测进入可视区 ≥50%每个区域每次会话仅触发 1 次
点击事件用户点击/触摸时立即上报不去重，每次点击都上报
停留时长visibilitychange=hidden 或 beforeunload每次离开页面上报一次
滚动深度滚动停止 500ms 后，检测达到阈值每个阈值 (25/50/75/100%) 仅触发 1 次

三、新增事件需求（本次需开发）

以下事件用于解决"用户停留多久、看到哪里、为什么流失"的分析盲区。按优先级排序。

3.1 会话级事件

优先级事件名称子事件触发时机事件参数开发说明
P1 hq_session_start cm_vshow 用户本次访问的第一个事件触发时 referrer: document.referrer（外部来源 URL）
utm_source: URL 参数中的 utm_source（无则空）
is_new_user: 1(localStorage无访问记录) / 0(有) 		判断"30 分钟内无事件"为新会话。首次加载页面时检查上次事件时间戳（存 localStorage），若 >30min 或不存在则视为新会话并上报。
P1 hq_session_end cm_vshow beforeunload 或 visibilitychange=hidden 且后续无活动 session_duration_ms: 从 session_start 到当前时间的毫秒数
pages_viewed: 本次会话内浏览的不同 page_id 数量 		用 navigator.sendBeacon 确保页面关闭时能发出。session_duration 取 performance.now() 或 Date.now() 差值。

3.2 页面停留 & 滚动

优先级事件名称子事件触发时机事件参数开发说明
P0 hq_page_stay cm_vshow 用户离开当前页面时（跳转到站内其他页 / 关闭 / 切到后台） page_id: 当前页面标识
duration_ms: 在本页可见状态停留的毫秒数 		记录 pageshow 时间 T1。监听 visibilitychange：页面 hidden 时计 duration = now - T1（排除 hidden 期间）。
站内跳转时也触发上报（SPA 则在路由切换前上报）。
用 sendBeacon 兜底 beforeunload。
P0 hq_scroll_depth cm_vshow 页面滚动到 25% / 50% / 75% / 100% 时 page_id: 当前页面
depth: 25 / 50 / 75 / 100（整数） 		计算方式: scrollTop / (scrollHeight - clientHeight) * 100。
每个阈值只触发一次（用 Set 记录已触发阈值）。
加 500ms debounce 避免滚动中频繁计算。

3.3 页面离开

优先级事件名称子事件触发时机事件参数开发说明
P0 hq_page_leave cm_click 用户离开当前页面的那一刻 page_id: 离开的页面
leave_type:
  navigate — 点击站内链接跳转
  external — 点击外链离开
  close — 关闭页面/标签页
  back — 浏览器返回
next_page_id: 如果是站内跳转，目标页面 ID（否则为空） 		站内跳转: 在 nav link 点击事件中上报（可复用 hq_click_nav_link 的时机）。
关闭/返回: beforeunload 中上报，leave_type 通过 performance.getEntriesByType('navigation') 或 popstate 判断。
无法 100% 区分 close 和 back 时，统一为 close。

四、代码实现参考

4.1 上报函数封装

// tracker.js — 统一上报入口 function trackEvent(eventName, subEvent, params = {}) { const payload = { event_name: eventName, sub_event: subEvent, // 通用参数 client_type: getClientType(), // 'PC' | 'iOS' | 'Android' url: window.location.href, refer_url: document.referrer, open_id: getOpenId() || '', timestamp: Date.now(), // 业务参数 ...params }; // 优先用 sendBeacon（页面关闭时也能发送） if (navigator.sendBeacon) { navigator.sendBeacon(REPORT_URL, JSON.stringify(payload)); } else { fetch(REPORT_URL, { method: 'POST', body: JSON.stringify(payload), keepalive: true }); } }

4.2 页面停留时长实现

// 页面可见时长追踪 let pageShowTime = Date.now(); let totalVisibleTime = 0; document.addEventListener('visibilitychange', () => { if (document.hidden) { // 切到后台，累加时长 totalVisibleTime += Date.now() - pageShowTime; reportStay(); } else { // 回到前台，重置起点 pageShowTime = Date.now(); } }); window.addEventListener('beforeunload', () => { totalVisibleTime += Date.now() - pageShowTime; reportStay(); }); function reportStay() { trackEvent('hq_page_stay', 'cm_vshow', { page_id: getCurrentPageId(), duration_ms: totalVisibleTime }); }

4.3 滚动深度实现

// 滚动深度追踪 const reportedDepths = new Set(); const THRESHOLDS = [25, 50, 75, 100]; let scrollTimer = null; window.addEventListener('scroll', () => { clearTimeout(scrollTimer); scrollTimer = setTimeout(() => { const scrollPct = Math.round( window.scrollY / (document.documentElement.scrollHeight - window.innerHeight) * 100 ); THRESHOLDS.forEach(t => { if (scrollPct >= t && !reportedDepths.has(t)) { reportedDepths.add(t); trackEvent('hq_scroll_depth', 'cm_vshow', { page_id: getCurrentPageId(), depth: t }); } }); }, 500); });

五、验收标准

检查项通过标准
参数完整性每条上报包含全部通用参数 + 该事件定义的全部业务参数，无字段缺失
参数值正确枚举值与文档定义一致（如 game_mode 只出现 sol/mp，不出现其他值）
去重逻辑曝光类事件同一会话同一对象只上报 1 次；滚动深度每阈值只触发 1 次
页面关闭兜底关闭页面时 hq_page_stay / hq_session_end 能正常上报（用 sendBeacon）
性能影响不阻塞主线程，上报异步执行，单页面事件上报 <50次/session
跨端一致性PC 和 Mobile 同一事件的参数结构、取值逻辑保持一致
自测覆盖每个事件至少在 PC Chrome + Mobile Safari 各触发一次并在 TLOG 后台可查到
