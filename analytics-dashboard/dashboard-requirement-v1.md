# DFoversea 数据看板建设需求 — v1.0（表格版）

> 展示形式：纯数据表格（类 Excel）
> 后端直接输出结果字段，前端渲染表格
> 日期: 2026-05-07

---

## 全局筛选

- **筛选项:** 开始日期 + 结束日期
- **影响范围:** 下方所有表格的数据查询时间范围

---

## 核心 KPI（2 张卡片）

| 指标 | 口径 | 对比 |
|------|------|------|
| UV | 最近一天的去重访客数 | WoW 环比 |
| PV | 最近一天的总页面浏览次数 | WoW 环比 |

---

## 表1: 每日流量趋势

**局部筛选:** 来源（全部 / 端内 / 端外）

**口径:** 每日的 PV、UV，以及当日新用户的 N 日留存率

| 列名 | 口径 |
|------|------|
| 日期 | 数据日期，降序排列 |
| PV | 当日页面浏览总次数 |
| UV | 当日去重访客数 |
| 次日留存 | 当日新访客中，次日回访的比例 |
| 3日留存 | 当日新访客中，第3日回访的比例 |
| 7日留存 | 当日新访客中，第7日回访的比例 |
| 14日留存 | 当日新访客中，第14日回访的比例 |
| 30日留存 | 当日新访客中，第30日回访的比例 |

> 留存天数不够时显示为空（如今天的数据无法算出7日留存）
