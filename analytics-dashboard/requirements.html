一、项目概述与数据采集现状

产品形态

  • Desktop 版: 5个核心页面（首页、我的数据、配装推荐、跳蚤市场、合成台）
  • Mobile 版: 移动端原型，功能与Desktop对齐
  • 技术栈: 纯静态前端（HTML/CSS/JS），无服务端，无构建工具
  • i18n: 支持 zh-CN / de 两种语言

数据上报配置

  • 上报平台: TLOG（original_game_id: 29158）
  • 通用参数:
    • client_type — PC / iOS / Android
    • url — 当前页面URL
    • refer_url — 前置页面URL
    • open_id — 用户ID
  • 事件类型: cm_vshow（曝光） / cm_click（点击）

三、核心指标体系

3.1 流量指标

指标定义计算方式
DAU日活跃用户数去重 open_id (当日有任意事件上报)
PV页面浏览量SUM(hq_exp_page)
UV独立访客去重 open_id (或匿名设备ID)
人均PV平均每用户浏览页数PV / UV
跳出率仅浏览1页即离开的占比单页会话数 / 总会话数

3.2 转化指标

指标定义计算方式
登录转化率点击登录→成功登录login_submit(success) / click_login_entry
配装复制率浏览配装页→复制配装码copy事件 / gun_builds页PV
分享转化率日报曝光→完成分享poster_share / daily_report曝光

3.3 留存指标

指标定义
次日留存第N日新用户在N+1日回访的占比
7日留存第N日新用户在N+7日回访的占比
30日留存第N日新用户在N+30日回访的占比

3.4 参与度指标

指标定义
平均会话时长从首次事件到末次事件的时间差均值
功能渗透率使用特定功能的用户占总活跃用户的比例
模式偏好比烽火地带 vs 全面战场的使用占比

四、数据报表需求

报表 1: 日常运营概览

  • 频率: 每日更新
  • 维度: 日期 × 平台(Desktop/Mobile)
  • 指标: DAU, PV, UV, 人均PV, 平均会话时长, 跳出率
  • 图表: 趋势折线图 + 环比/同比变化

报表 2: 页面流量分布

  • 频率: 每日更新
  • 维度: page_id × 日期
  • 指标: 各页PV/UV, 页面停留时长, 进入率, 退出率
  • 图表: 堆叠柱状图 + 桑基图（页面流转路径）

报表 3: 登录漏斗

  • 频率: 每日更新
  • 维度: login_method × login_type × login_channel
  • 指标: 各步骤转化率, 登录成功率, 错误码分布
  • 图表: 漏斗图 + 错误码饼图

报表 4: 内容互动分析

  • 频率: 每周汇总
  • 维度: game_mode × 内容类型(日报/密码/展馆)
  • 指标: 曝光量, 互动量(点击/复制/分享), 互动率
  • 图表: 曝光-互动双轴折线图

报表 5: 配装功能分析

  • 频率: 每周汇总
  • 维度: 武器类型 × game_mode × 配装方案类型
  • 指标: 浏览量, 复制量, 复制转化率, 热门武器TOP10
  • 图表: 水平条形图 + 漏斗

报表 6: 用户留存

  • 频率: 每日更新
  • 维度: 注册日期(cohort) × 回访天数
  • 指标: N日留存率, 留存曲线
  • 图表: 留存矩阵热力图

报表 7: 分享渠道效果

  • 频率: 每周汇总
  • 维度: share_channel × game_mode
  • 指标: 各渠道分享次数, 渠道偏好占比
  • 图表: 饼图 + 趋势

五、数据分析方案

5.1 用户旅程分析

基于 refer_url + url + 事件序列，构建典型用户路径：

路径1: 首页 → 我的数据 → 切换模式 → 查看战绩
路径2: 首页 → 配装推荐 → 选择武器 → 复制配装码
路径3: 首页 → 日报曝光 → 分享按钮 → 海报 → 渠道分享
路径4: 登录入口 → 选择方式 → 提交 → 成功/未找到角色 → 下载/换号

5.2 A/B分析维度

  • 平台对比: Desktop vs Mobile 在相同功能上的转化差异
  • 登录方式对比: Level Infinite vs Garena 的转化率与留存差异
  • 游戏模式对比: SOL(烽火) vs MP(全面战场) 的用户活跃度与深度
  • 语言对比: zh-CN vs de 用户的行为差异

5.3 异常监控

监控项阈值告警逻辑
登录失败率>20%error_code != 0 占比超阈值
DAU波动环比下降 >30%自动告警
页面加载异常PV=0持续5分钟某page_id无数据
"未找到角色"激增环比 >50%服务端可能异常

5.4 核心分析问题

  1. 配装复制是核心价值动作，如何提升复制转化率？→ 分析从页面浏览到复制的流失节点
  2. 登录流失在哪一步最严重？→ 漏斗各步转化率 + error_code分布
  3. 日报分享渠道效果如何？→ 各渠道分享量 & 用户复访率
  4. 模式偏好对用户留存有何影响？→ SOL用户 vs MP用户的留存对比
  5. 新用户引导是否有效？→ 新用户首次会话行为序列 & 是否触达核心功能

六、漏斗模型设计

漏斗 A: 登录转化漏斗

hq_click_login_entry → hq_exp_login_modal → hq_click_login_method_select → hq_click_login_submit(success) → 完成登录

分支: submit失败 → norole弹窗 → gotodownload / otheraccount / dismiss

漏斗 B: 日报分享漏斗

hq_exp_daily_report → hq_click_daily_share_btn → hq_exp_daily_poster_modal → hq_click_daily_poster_share

漏斗 C: 配装使用漏斗

hq_exp_page(gun_builds) → 选择武器 → 查看方案 → 复制配装码

漏斗 D: 数据查看漏斗

hq_exp_my_data → hq_click_game_mode_switch → hq_click_profile_tab → hq_click_match_detail

七、用户分群策略

分群名称定义分析目的
核心玩家登录用户 + 周访问≥3次 + 使用配装功能分析高活跃用户行为模式
数据查看者主要访问my_data页 + 查看战绩了解数据功能的粘性
工具使用者频繁使用配装复制/密码复制评估工具功能价值
社交分享者有分享行为(poster_share)的用户社交传播效果分析
流失风险用户7日内无回访的活跃用户流失预警 & 召回策略
新用户首次访问≤7天的用户引导效果评估
游客用户未登录状态浏览登录引导策略优化
